## 7. Verified facts (don't re-research them; sources are in plan B1)

- **Plans and access:**
  - Cloud sessions need Pro, Max, Ultra or Team, or an Enterprise premium seat.
  - Guest passes give a 7-day Pro trial, and each user has only a few.
- **Network:** access levels are None, Trusted, Full and Custom.
  - Trusted covers PyPI, GitHub, `raw.githubusercontent.com` and `*.amazonaws.com`.
  - It does *not* cover the DEA or Earth Search STAC APIs, Hugging Face or Source Cooperative, so the workshop uses **Full**.
- **VM:** Ubuntu 24.04 x86-64, **4 vCPU, 16 GB RAM, 30 GB disk, no GPU**. Python with uv, Docker and Chrome are preinstalled.
- **Setup script:** ≤ 64 KB, and cached if it finishes in under about 5 min. The cache rebuilds after about 7 days or when the script changes.
- **Command timeouts:** 2 min by default and 10 min at most in the foreground, plus up to 30 min in the background. The `BASH_DEFAULT_TIMEOUT_MS` environment variable changes the default.
- **Cloud permission modes:** Auto (if offered), Accept edits and Plan.
- **GitHub limits:** files over 100 MiB are blocked, files over 50 MiB get a warning, browser uploads are capped at 25 MiB, and repos should ideally stay under 1 GB.
- **Local models:** Ollama ≥ 0.14 serves the Anthropic Messages API, but Anthropic's docs don't support routing Claude Code to non-Claude models.
- **Embeddings:**
  - AlphaEarth annual embeddings are on Source Cooperative (CC BY 4.0, 2018–2025, with a required attribution string).
  - TESSERA is available via `geotessera`: MIT code, Python ≥ 3.12, 2017–2025 with partial coverage; the data licence is still to be confirmed.
- **ALA:** use `https://biocache-ws.ala.org.au/ws/occurrences/search`.
