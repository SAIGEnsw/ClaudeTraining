2. The Claude Prompt Library (your working reference)
Link: https://docs.anthropic.com/claude/prompt-library
How to use it:
1.	Open the link. You'll see a grid of named prompts for real tasks — optimized prompts for a breadth of business and personal tasks, things like extracting insights from long reports, a meeting scribe, an email extractor, a second-grade simplifier, and dozens more. Anthropic
2.	Click any one that's close to something you actually do. Read the prompt itself, not just the output.
3.	"Reverse-engineer" it by asking: why did they assign a role? Why structure it that way? Many use XML-style tags like <task> and <output_format> to separate instructions from content — notice that pattern, because it's a core Claude technique.
4.	Copy a prompt, swap in your own details, and run it in Claude. Then tweak. Building your own small collection of "prompts that worked" is the real payoff.
3. Anthropic's docs on prompt and context engineering
Prompt engineering overview: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview
How to approach it:
1.	Save this for after Claude 101 — it's slightly more technical and assumes you know the basics. It's written for people building with Claude, but the principles apply to chat use too.
2.	Read the overview page first, then follow the side-menu links into specific techniques (being clear and direct, using examples, giving Claude a role, etc.). The page also points you to Anthropic's prompting tools and interactive tutorials if you prefer hands-on learning. Anthropic
3.	For long-document work specifically, the docs note that when working with large or data-rich inputs of 20k+ tokens, you should structure your prompt carefully to get the best results — that's the heart of "context engineering": deciding what to put in front of the model and how to organize it.
